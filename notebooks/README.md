# Notebooks

Interactive demonstrations of the data pipeline, 3D geometry operations, and joint 2D+3D molecular diffusion:

* Loading pre-collated heavy-atom QM9 batches, inspecting atom-count distributions, and rendering 2D molecular graphs.
* Center-of-mass zeroing, uniform random 3D rotations, chirality preservation, and Kabsch alignment with 3D molecular overlays.
* Karras EDM preconditioning curves, single-batch diffusion training convergence, conformer sampling, and animated 3D reverse-diffusion trajectories.
* Loading saved run checkpoints and metric logs, evaluating test-set conformer RMSD and 2D atom/bond loss, animating test-molecule diffusion trajectories, and running conditioned (`CCO`, `c1ccccc1~U~U(=U)`) and unconditioned (`U.U.U.U.U`) 2D+3D molecule generation.
