# Notebooks

Interactive demonstrations of the data pipeline, 3D geometry operations, and coordinate diffusion training:

* Loading pre-collated QM9 batches, inspecting atom-count distributions, and rendering 2D molecular graphs.
* Center-of-mass zeroing, uniform random 3D rotations, chirality preservation, and Kabsch alignment with 3D molecular overlays.
* Karras EDM preconditioning curves, single-batch diffusion training convergence, conformer sampling, and animated 3D reverse-diffusion trajectories.
* Loading saved run checkpoints and metric logs, evaluating test-set conformer RMSD, animating test-molecule diffusion trajectories, and sampling conformers from arbitrary SMILES strings.
